# Employee Management System

A full-stack Employee Management System built with React, Node.js, Express.js, and MySQL.

## 🚀 Tech Stack

### Frontend

- React
- React Router
- Bootstrap
- Bootstrap Icons

### Backend

- Node.js
- Express.js
- MySQL
- mysql2
- bcryptjs
- JSON Web Token (JWT)
- dotenv
- CORS

### Development Tools

- Nodemon
- Git
- GitHub
- Postman
